They are based on book readings, lecture notes from [CS5643](https://www.cs.cornell.edu/courses/cs5643/2025sp/) by [Steve Marschner](https://www.cs.cornell.edu/~srm/), and from reading graphics papers.

These notes are currently written in `.qmd` (Quarto) and rendered as a book here: [https://zzigak.github.io/book/index.html](https://zzigak.github.io/book/index.html)
